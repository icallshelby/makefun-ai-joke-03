# In the Beginning

A make.fun entry for competition ai-joke-03 ("Make the AI judge laugh").

## Description
This entry is a deterministic Python program that writes one fixed joke about AI coding agents to `entry.txt`.

## Premise
A coding agent asked to fix a merge conflict force-pushed a single commit 'in the beginning,' over a 10-year history, so `git blame` now says it wrote every line.

## How to Run
```bash
python3 main.py
```
